# 작업 중 판단 기록

사용자가 "물어볼 게 생기면 합리적으로 판단해서 진행하고, 판단한 내용은 여기 적어두라"고 한 항목들.

## 1. "사러 가기" 링크: 에이블리 제외, 무신사·29CM 두 곳만 사용

- WebFetch 도구가 이번 주 사용량 한도에 걸려서 실제 페이지를 직접 열어 확인할 수 없었음.
- 대신 WebSearch로 각 쇼핑몰의 실제 검색 URL 패턴을 구글에 색인된 진짜 페이지로 확인:
  - 무신사: `https://www.musinsa.com/search/goods?keyword=<검색어>` — 구글에 실제 색인된 다수의 musinsa.com 페이지로 확인됨.
  - 29CM: `https://www.29cm.co.kr/store/search?keyword=<검색어>` — 마찬가지로 실제 29cm.co.kr 페이지로 확인됨.
  - 에이블리(a-bly.com/m.a-bly.com): 검색해봤지만 정확한 검색 URL 파라미터를 못 찾음(모바일 전용 SPA라 구글에 검색 URL이 노출되지 않는 듯).
- **판단**: "지어내지 말고 확실히 열리는 주소로만"이라는 요구가 우선이라, 확인 안 된 에이블리 패턴을 추측해서 넣는 대신 무신사·29CM 두 곳만 쓰기로 함. 사용자가 예시로 든 세 곳("무신사·29CM·에이블리 같은") 중 "~같은"이 예시라는 뜻으로 해석.
- 매핑 기준: 패스트패션/리세일형 브랜드(스파오, 탑텐, 유니클로, 무지, 에이블리, 에이랜드, 시에로)는 무신사로, 디자이너/프리미엄 브랜드(코스, 아크네 스튜디오, 메종 마르지엘라, 구찌, 젠틀몬스터, 칼하트WIP, 폴로 랄프로렌, 아워레가시)는 29CM으로, 스포츠 브랜드(뉴발란스, 뉴에라, 노스페이스)는 무신사로 보냄.
- 검색어는 `브랜드 제품명`을 URL 인코딩해서 넣음. 상품 상세 페이지가 아니라 "검색 결과" 페이지라서, 그 브랜드 제품이 실제로 그 쇼핑몰에 없어도 페이지 자체는 항상 뜬다(검색 결과 0건으로 뜰 수는 있음 — "확실히 열리는 페이지"라는 요구사항은 만족하지만 "그 상품이 거기 있다"는 보장까지는 아님).
- **내일 발표 전 꼭 확인할 것**: 실제 브라우저로 몇 개 샘플 링크를 직접 열어서 진짜 로딩되는지 눈으로 한 번 더 확인 권장 (이 세션은 WebFetch 한도 때문에 못 함).
